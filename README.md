# 🤖 Curis - AI Robotic Wound Care

## 🌟 Introduction ✨
🤖 Curis is an **AI-powered robotic wound care system** 🏥 that significantly reduces **human intervention in wound treatment**. By leveraging **multi-agent AI systems, inverse kinematics, and LLM-powered decision-making**, Curis automates wound analysis, medicine application, and report generation, ensuring **precise and efficient** medical assistance.

## 🚀 Key Features 🎯
### 1️⃣ 🤖 AI-Powered Multi-Agent System 🏥
✅ **Injury Analysis** - AI models analyze wound images and provide **detailed reports**.
✅ **Clinical Pharmacology** - AI selects the appropriate **medications and antiseptics**.
✅ **Medical Report Writing** - Automated medical documentation **reduces manual effort**.

### 2️⃣ 🦾 Autonomous Robotic Arm 🏗️
✅ **Inverse Kinematics Control** - Uses precise **movements to apply medicine**.
✅ **Cotton Ball Mechanism** - Picks, applies, and disposes of cotton **automatically**.
✅ **Arduino Mega Integration** - Triggers the robotic arm via **serial communication**.

### 3️⃣ 🔄 Workflow Automation ⚙️
✅ **Multi-Agent AI Workflow** - Coordination between AI agents for decision-making.
✅ **Medical Data Storage** - Organizes patient details, wound history, and treatment logs.
✅ **Web Interface for Image Uploads** - Allows users to upload wound images for analysis.
